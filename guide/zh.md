
# Klirena 用户指南

·

## 入门

Klirena 可在手机（iPhone、Android）和电脑（klirena.com/panel）上使用同一个账户；在一处录入的数据会立即在另一处显示。

### 安装与注册

1. 在 App Store 或 Google Play 中搜索“Klirena”并下载应用。
2. 点按**注册**；输入电子邮件和密码，并同意使用条款和隐私政策。
3. 点击发送到您邮箱的确认链接。未确认的账户无法登录；如果没有收到邮件，请查看垃圾邮件文件夹。发件人是 support@klirena.com。
4. 登录。如果忘记密码，请在登录页面点按**忘记密码**，申请重置邮件。

### 设置向导

首次登录时，主页会出现设置卡片；之后也可以从设置 > 设置向导打开。步骤依次如下：

1. **诊所信息和 Logo：** 诊所名称、医生姓名、地址、电话、社交媒体账号。Logo 会显示在 PDF 报告、拼贴图和发给患者的页面上。
2. **第一位患者：** 只需姓名和电话。
3. **第一张照片：** 按角度引导拍摄一张就诊照片。
4. **提醒消息：** 编辑您的预约提醒文本。
5. **在线预约：** 开通供患者自行预约的页面。
6. **团队：** 邀请助理或第二位医生。

您可以跳过某些步骤，以后再回来；已完成的步骤会保持标记。

### 诊所工作方式

在诊所信息中选择您的诊所如何运作；界面会据此简化。

| 选项 | 适用对象 | 有何变化 |
|---|---|---|
| 美容 / 治疗诊所 | 只做治疗项目的诊所 | 新就诊以项目方式开始 |
| 门诊（仅问诊） | 只做问诊的诊室 | 新就诊以问诊方式开始；患者页面中隐藏疗程套餐、健康问卷和前后对比 |
| 混合 | 两者都做 | 新就诊默认打开上次使用的类型 |

在应用中通过设置 → 诊所信息更改，在面板中通过设置 → 诊所信息更改。为某位患者创建项目或复诊就诊后，被隐藏的部分会在该患者处重新显示。

### 用户和角色

通过设置 > 用户 > 添加用户，输入电子邮件并选择角色来添加团队成员。每家诊所最多 5 位用户。

| 角色 | 可查看和可操作的内容 |
|---|---|
| 管理员 | 全部：账务、用户、设置 |
| 用户（助理、医生） | 患者、就诊、照片、预约、同意书；看不到账务 |

### 语言

在设置 > 语言中，从 10 种语言中选择。发给患者的消息、同意书页面、预约页面和患者中心也会使用该语言。

### 订阅

设置顶部的高级版卡片中显示各种方案。订阅通过您的 App Store 或 Google Play 账户购买、管理和取消；Klirena 不保存付款信息。

## 患者

一切都从患者卡片开始：就诊、照片、同意书、预约、套餐和账户集中在一个页面。

### 添加患者

1. 在主页点按**添加患者**，或点按底部的 + 按钮。
2. 输入姓名和电话；这些就足够了。电话会以带国家代码的统一格式保存，WhatsApp 消息会发送到这个号码。
3. 您还可以选择性地添加出生日期、性别、电子邮件、国籍和备注。

### 搜索和列表

在患者页面中，可按姓名或电话搜索。列表按最近一次就诊排序。在面板（患者标签）中，同样的列表以更宽的表格显示。

### 患者详情

| 部分 | 内容 |
|---|---|
| 信息 | 身份、联系方式、备注；点按编辑图标修改 |
| 就诊 | 按日期排列的所有就诊，以及项目和照片数量 |
| 同意书 | 已签署和待签署的同意书及其 PDF |
| 预约 | 过去和未来的预约 |
| 疗程套餐 | 已购买的套餐、剩余次数 |
| 账户 | 费用、付款、剩余欠款（仅管理员） |
| 文件 | 已上传的化验单、出院小结、PDF 和图片 |

患者详情中的快捷操作：通过 WhatsApp 联系、拨打电话、发送同意书、分享照片、对比（拼贴）、患者中心链接、健康问卷。

### 患者中心

患者中心是一个页面，患者可以通过一个链接查看自己的预约、套餐、共享的照片和同意书。请在患者详情中发送链接；患者使用手机号后 4 位登录。

### 健康问卷

可通过 WhatsApp 从预约或就诊中发送问卷；在线预约之后也可以自动请求填写。患者在自己的手机上回答过敏、用药、怀孕、既往项目等问题。有风险的回答会在主页上以警告形式显示，并保存在患者卡片中。

### 删除和合并患者

在患者详情的菜单中删除；该患者的就诊、照片和同意书会一并移除，所以请先确认。导入时重复的患者会被自动跳过。

## 就诊和照片

就诊是患者每一次来诊所：日期、部位、所做项目、照片、诊断、注射图和所用产品都记录在就诊中。

### 新就诊

1. 打开患者，点按**添加就诊**。
2. 选择部位：脸、脖子、腹部、腿或其他。
3. 选择就诊类型：**项目**、**复诊**或**问诊**。选择复诊时，需要从尚未复诊的既往就诊中选一个；复诊会关联到该次就诊，前后对比会自动配对。选择问诊时只需选择日期（见问诊就诊）。
4. 选择日期（默认今天；可选过去的日期，不能选未来的日期）。
5. 输入所做项目，或从列表中选择（肉毒素、填充、中胚层疗法、化学换肤、PRP、水光……）。例如：“3 个部位肉毒素，唇部填充”。

### 引导拍照（5 个角度）

相机依次要求拍 5 个角度：正面、右 45°、左 45°、右侧面、左侧面。

- 上一次就诊的照片会作为淡淡的背景显示在屏幕上；请让患者回到同样的姿势再拍。
- 系统会测量手机的倾斜度；手机不平时会提示。这样前后照片的角度保持一致。
- 您可以跳过某个角度，稍后再补拍。也可以从相册添加照片。
- 照片不会保存到手机相册，而是加密保存到诊所的云端档案。

提示：相同的光线、相同的背景和相同的距离最能体现前后差异。请让患者摘掉首饰、卸妆，并把头发向后束起。

### 就诊详情

| 卡片 | 用途 |
|---|---|
| 照片 | 按角度显示照片；点按可放大，滑动可在角度之间切换 |
| 诊断 (ICD-10) | 按代码或名称搜索（如 L81.1、黄褐斑、D22.3 痣）。标准诊断列表和美容诊断已备好 |
| 注射图 | 在面部示意图上标记注射点，填写产品和用量 |
| 治疗方案 | 为后续疗程计划的部位和产品 |
| 使用的产品 | 带批号 / 序列号；会从库存中扣除 |
| 备注 | 病史、检查发现、建议 |
| 费用 | 本次就诊的费用行和付款（见费用部分） |

在注射图中填写的产品名称如果与库存中的名称相同，用量会自动从库存中扣除。

### 问诊就诊

问诊就诊用于不做项目的就诊：记录主诉和检查发现，开具处方和化验，必要时取得同意书。

1. 打开患者，选择**添加就诊** → **问诊**，输入日期后点按**开始问诊**。这一步不会询问部位、常用项目、照片和费用。
2. 在问诊页面中依次填写：慢性病、主诉、病史、检查发现、结论和建议。
3. **处方：** 每行写一种药物。**分享处方**会生成带诊所 Logo、患者和诊断信息的 A5 PDF；可通过 WhatsApp、电子邮件或打印机发送。这不是电子处方。
4. **化验：** 写下所开的化验项目。结果出来后，拍照或添加 PDF；文件也会保存到患者的文件中。
5. **同意书：** 如果要做有创操作，请用**发送同意书**把同意书发给患者；同意书会关联到本次就诊。您也可以选择并关联一份之前已签署的同意书。
6. 诊断和费用的填写方式与其他就诊相同。如果用了药物或疫苗，请看下面的部分。

这些就诊在患者列表和日程中显示为**问诊**；在统计中单独一行计数。如果问诊是误开的，可以删除该就诊。

### 已用药物和疫苗

给患者做的注射、疫苗或药物，从库存中选择后记录在就诊的**已用药物 / 疫苗**卡片中。这样库存会扣减，批号也会被记录下来。

1. 在卡片中选择产品，或扫描盒上的二维码。以 ml 定义的产品按 ml 询问用量，其他产品按数量询问。
2. 在弹出的窗口中选择给药途径：IM、SC、ID、IV、局部或口服。填写给药部位（如左三角肌）。
3. 标记剂次：第1剂、第2剂、第3剂或加强针。如果填写了下一剂的日期，患者到期时会出现在**回访提醒**列表中，并且提醒消息已准备好。
4. 如果患者卡片上有过敏记录，卡片上方会出现红色警告；给药前请核对。如果没有过敏记录，会显示绿色的“无过敏记录”。

在面板中，同一张卡片在就诊详情中以**已用药物 / 疫苗**为标题显示。

### 前后对比拼贴

至少需要 2 次就诊。

1. 在患者详情中点按对比按钮。
2. 选择就诊（如项目当天和第 2 周复诊）以及角度。
3. 在拼贴编辑器中调整版式、日期和 Logo 的显示。
4. 保存或分享拼贴图。

### PDF 报告

在就诊详情中点按 PDF报告。版式选项：

| 版式 | 适用场合 |
|---|---|
| 单页总览 | 所有角度在 1 页上；适合分享 |
| 每角度一页 | 大图且详细；适合存档和法律记录 |
| 紧凑 | 每页 2 个角度 |

“与上次”选项会把本次与上一次就诊并排放置。内容中的所做项目、年龄和日期差、患者电话都可以开关。报告会带上诊所 Logo 和信息。

### 向患者发送照片

在患者详情中点按分享图标，选择照片。一个有时效的安全链接会通过 WhatsApp 发出；您可以随时撤销该链接。照片文件不会作为附件发到 WhatsApp，所以控制权仍在您手中。

### 文件

把化验结果、出院小结、外院报告等 PDF 和图片上传到患者详情的文件中。在面板中也可以拖放添加。

## 同意书

患者在自己的手机上用 6 位验证码验证后签署同意书；已签署的 PDF 连同时间戳保存到患者档案。不需要纸张、扫描仪和文件柜。

### 准备模板

1. 打开设置 > 同意书模板。
2. 点右上角的图标添加语言；所选语言的 5 个现成模板会被载入。对于外国患者，可以添加多种语言。
3. 打开模板，按您的实际做法修改文本，或新建模板（同意书名称 + 同意书内容）。实时预览会显示患者将看到的样子。

重要：现成模板只是起始文本，未经律师审核。使用前请请法律顾问审阅；因内容产生的责任由诊所所有者承担。

### 发送同意书

1. 在患者详情中点按**发送同意书**并选择模板。
2. 消息已准备好：链接和 6 位验证码。通过 WhatsApp 发送，或复制链接。验证码 24 小时内有效。
3. 如果患者在诊所里，可以在自己的手机上打开并当场签署。

### 患者端签署

1. 患者打开链接，输入 6 位验证码。
2. 阅读同意书文本。文本按患者的语言显示。
3. 输入证件号，勾选确认框。
4. 用手指在屏幕上签名，然后点按“签署”。

如果有遗漏的项目（签名、确认框、无效的证件号），页面会指出缺少哪一项。

### 签署之后

- 已签署的 PDF 包含文本、签名、身份验证、日期时间和时间戳，以不可更改的方式保存。另外还会保存一份备份。
- 它会显示在患者详情的同意书中，以及设置 > 已发送的同意书中。待签署（尚未签署）的同意书也在这个列表中。
- 您可以把同意书关联到相应的就诊（就诊详情 > 关联同意书）。关联可以取消。
- 您可以取消尚未签署的同意书；链接随即失效。

患者也可以在患者中心看到自己已签署的同意书。

## 预约和日程

预约簿可避免冲突，一键发送提醒，并通过在线预约让患者自己预约。

### 添加预约

1. 在主页点按**添加预约**或 + 按钮；或者在预约页面点按空闲时段。
2. 选择患者（也可以在这里添加新患者）。
3. 选择服务、时长、医生以及诊室 / 设备。
4. 保存。同一位医生、诊室或设备在同一时间不能有第二个预约。

点按预约可进行编辑、移动、取消，或标记为“已到” / “未到”（未到率会显示在统计中）。患者到诊后，可从这里开始就诊。

### 医生、诊室、屏蔽时段

| 设置 | 位置 | 作用 |
|---|---|---|
| 医生 | 设置 > 医生 | 每位医生可以有自己的工作时间；可以在在线预约中显示或隐藏。只有一位医生的诊所不需要 |
| 诊室和设备 | 设置 > 诊室和设备 | 防止激光、HIFU 等单台设备上的冲突 |
| 屏蔽时段 | 设置 > 屏蔽时段 | 为手术、休假、假期屏蔽某一天或某个时间段；这些时段不会在在线预约中显示 |

预约簿可以按医生筛选。

### 提醒

在预约页面点按预约，选择 WhatsApp 或短信；消息已带好患者姓名、日期和时间，您只需点按“发送”。在设置 > 提醒中修改消息文本；如果该字段为空，则使用默认文本。

### 候补名单

对于已满的日期，把患者加入候补名单。有预约取消时，可一键通过 WhatsApp 向名单中的患者发送“有空位了”的消息。

### 在线预约

1. 在设置 > 在线预约中开通。
2. 在面板的在线预约标签中编辑服务、时长和工作时间。
3. 复制链接或下载二维码；把它添加到 Instagram 个人简介、Google 商家资料、WhatsApp Business 和您的网站。在 Instagram 中：编辑主页 > 链接 > 添加外部链接。

患者看到空闲时段，选择服务和（如有）医生，填写姓名和电话。预约会以“🌐 在线”标签出现在您的预约簿中。如果您愿意，之后会自动请求填写健康问卷。

### 手机日历

通过设置 > 日历订阅，把预约添加到 iPhone、Google 或 Outlook 日历。这是单向的（在日历中的更改不会同步到 Klirena）。为保护隐私，可以隐藏患者姓名。

### 日程

在面板中，日程标签以大屏幕显示日视图和周视图；适合前台电脑使用。

### 回访提醒和 Google 评价

系统会根据项目自动计算复查和重复治疗的时间（肉毒素、填充、中胚层疗法、PRP 等每种项目有各自的间隔）。到期的患者会列在主页和回访提醒页面。

1. 点按患者旁边的 WhatsApp 按钮；复查或再次治疗的消息已准备好。您可以在设置中编辑文本（[ad]、[islem]、[klinik] 字段会自动填入）。
2. 向满意的患者邀请 Google 评价：在设置 > 提醒中输入一次您的 Google 评价链接，消息就会带着链接准备好。

统计页面显示发送了多少条消息，以及其中有多少位患者预约了。

## 费用、套餐和账务

费用在就诊中录入；收款、剩余欠款、分期和套餐次数会自动记入患者账户和账务。这一部分只有管理员用户能看到。

### 就诊中的费用和付款

1. 在就诊详情中点按**添加费用**。
2. 输入金额和说明。如果有多个项目，用**按项目拆分**添加行（如 问诊 1,500 + Plexr 8,000）。每个有金额的行都必须填写项目名称。
3. 选择付款：全额、部分或稍后。付款方式：现金、刷卡、转账。
4. 部分付款或稍后付款的金额，会作为欠款记入患者账户。

如果就诊中所用产品填写了批次成本，就诊卡片还会显示产品成本和利润。

限制：金额不能少于已收款项；分期费用需要在患者账户中修改。

### 患者账户和分期

患者详情中的账户卡片显示所有费用、付款和未结欠款。点按**收款**时，金额先记入下一期分期，没有分期则记入未结欠款。分期数在录入费用或套餐时确定；到期的分期会在主页上以警告形式显示。

### 疗程套餐

套餐是预先售出的疗程次数（如 中胚层疗法 5 次）。

1. 患者详情 > 疗程套餐 > 添加套餐。
2. 输入套餐名称、次数、可选的有效期、套餐价格和分期数。如果填写了价格，会作为欠款加入患者账户。
3. 每次疗程时，在就诊详情中点按“扣除套餐次数”。该次疗程不再另外收费；卡片显示“[已用] / [总共] 次”。
4. 扣错的次数可用撤销纠正。取消套餐时，已用的次数仍会保留。

套餐状态：有效、已完成、已过期、已取消。患者可以在患者中心看到自己的剩余次数。

### 账务页面

| 部分 | 显示内容 |
|---|---|
| 汇总 | 所选月份的收入、支出和净额；按类别和收款方式的分布 |
| 明细 | 所有收入和支出记录；患者、日期、金额 |
| 应收 | 患者的未结欠款和逾期分期 |
| 按月 | 逐月的收入—支出—净额 |

就诊之外的收入（产品销售等）和支出，用“收入” / “支出”按钮录入。支出类别：产品采购（库存）、房租、员工 / 工资、水电等账单、税费 / 社保、广告、会计 / 咨询、设备、其他。

### 日结

每天结束时点按**日结**；会显示当天的现金收款，并标记为已日结。未日结的日期会在主页上提醒。

### 发送给会计

“发送给会计 (Excel/CSV)”会把所选时期的全部明细导出为文件。在面板中也可以从财务标签下载。

## 库存

扫描盒上的二维码入库，在患者身上使用时数量自动扣减。每位患者用了哪个批次始终可查。

### 定义产品

设置 > 库存（面板中的库存标签）> 添加产品：

| 字段 | 说明 |
|---|---|
| 产品名称 | 在注射图中用同样的名称填写（如“20u Botox”）；用量会自动从库存中扣除 |
| 单位 | 单位 (u) 或 ml |
| 每盒含量 | 每盒有多少单位 / ml（如 100 u 毒素、1.5 ml 填充剂）；会乘以盒数，成本据此计算 |
| 最低库存 | 低于此数量时提醒 |
| 开封后使用期限 | 以天为单位；已开封的瓶子到期时提醒 |
| 产品条码 (GTIN) | 首次扫描时自动保存 |

### 入库（批次）

1. 点按**批次入库**或**扫描条码 / 二维码**。
2. 把盒上的二维码 (DataMatrix) 对准取景框。GTIN、批号、序列号和有效期会从二维码中读取。
3. 如果是第一次扫描该条码，请选择它是哪个产品，或新建产品；之后再扫描时会自动识别产品。
4. 输入数量、单位成本和供应商。如果同一批次已存在，数量会加到现有批次上。

### 日常使用

- 在就诊中添加所用产品（选择批次），或写入注射图；库存会扣减，批次会记录到患者的这次就诊中。
- 打开瓶子时点按**已开瓶**；系统会跟踪开封后的保存时间。
- 用损耗 / 销毁和盘点（+ 多、− 少）使库存与实际一致。
- 提醒：库存不足、临近有效期、已开封瓶子超期。它们也会显示在主页上。
- “使用过该批次的患者”：如果某个产品被召回，会列出使用了该批次的所有患者。

### 成本和利润

如果入库时填写了单位成本，就诊卡片和利润报告会计算实际材料成本。没有填写盒价的产品，会在报告中提示“成本缺失”。

## 统计和报告

统计页面（应用中的统计，面板中的统计标签）显示所选时期内来了多少患者、哪些项目带来了多少收入，以及回访是否有效。

### 选择时期

本月、上月、选择月份、今年、去年、最近 12 个月。在面板中点击月份图表中的一根柱子，就会打开该月。数字旁边的百分比是相对上一时期的变化。

### 指标

| 指标 | 含义 |
|---|---|
| 新患者 | 本期首次登记的患者 |
| 就诊 + 复诊 | 项目就诊和复诊就诊，分别计数 |
| 在线 | 来自在线预约的预约 |
| 预约 | 总数、已完成、已取消和未到率 |
| 召回转化 | 发送的消息数 → 预约的患者数 |
| 收入 | 本期的收款（管理员） |
| 产品消耗 | 按产品统计使用的单位 / ml |

### 项目列表

每个项目类别显示“N 次就诊 · X（M 笔收款）”：就诊次数、该项目带来的收入，以及收入来自多少笔付款。就诊次数和收款笔数可以不同；分期或部分付款会为一次就诊记录多笔收款。

问诊规则（仅用于统计）：

- 对于“问诊 + Plexr”这样的费用，问诊行不单独计算；其收入计入项目 (Plexr)。
- 只写了“问诊”的费用，如果该次就诊的项目已确定，就计入该项目。
- 没有关联到就诊的付款，会关联到同一患者同一天的就诊。

这样“问诊”一行才真正只显示仅为问诊而来的患者。账务记录不受影响。

### 利润报告

管理员可以按项目查看收入 − 材料成本 = 利润。为了让报告准确，报告会把以下缺失项列为提示：

- [n] 次就诊没有填写费用。
- [n] 次收费就诊没有填写材料；成本按 0 计算。
- [n] 次就诊所用产品没有填写盒价；成本不完整。

### 导出

账务明细可导出为 Excel/CSV，全部数据可在面板的备份标签中下载（见网页面板）。

### 导入（从旧系统迁移）

患者列表、就诊历史和照片可一次性从任何系统迁移。

1. 从旧系统中，把患者列表和项目 / 就诊列表导出为 Excel 或 CSV，照片文件夹保持原样（或打包为 ZIP）导出。文件的第一行必须是列标题；每个文件最多 20,000 次就诊。
2. 把所有文件一起拖到导入标签；系统会自动区分各文件是什么。
3. 检查列的对应关系，点按预览和开始。顺序是：先患者，然后就诊，最后照片。
4. 在就诊列表中有、但档案中没有的患者会被自动创建。把没有匹配的照片文件夹关联到某位患者，或作为新患者添加。

重复项会被跳过。每次导入都可以撤销：导入的照片和变空的就诊，或没有添加照片 / 文件的已导入就诊，会被删除。如果您无法导出，请写信给 support@klirena.com，我们来帮您迁移。请不要通过电子邮件发送患者数据。

### 安全上传链接

如果文件在别人手里（旧系统公司、您的助理），请在设置 > 安全上传链接中创建链接并发给对方。对方把文件上传到该页面，文件会直接进入您的面板；不需要电子邮件或 U 盘。链接有时效，您可以随时撤销。

### 备份和数据下载

数据会自动加密保存在云端，每晚另行备份；您不需要自己备份。如果想要自己的副本，请从备份标签下载：

| 格式 | 内容 |
|---|---|
| ZIP | 所有患者、就诊、照片和文件，按文件夹整理；建议用作完整备份 |
| HTML | 可以直接在浏览器中查看照片的报告 |
| JSON / CSV | 用于导入其他程序的原始数据 |

在应用中，设置 > 数据访问会引导到相同的选项。

## 安全、数据保护和支持

患者数据通过加密连接保存在安全的云服务器上，每家诊所只能看到自己的数据，并且每晚备份。您这边需要做的事情如下。

### 您需要做的事

- 每位用户使用自己的账户；不要共用密码。离职的员工请立即在设置 > 用户中移除。
- 选择至少 8 个字符、没有在别处使用过的密码；在面板中通过设置 > 更改密码修改。
- 在手机上开启屏幕锁。
- 向患者发送照片时，使用有时效的分享链接，不要作为 WhatsApp 附件发送。
- 不要通过电子邮件发送患者数据；需要接收文件时，请使用安全上传链接。
- 寻求支持时，请在截图中遮住患者姓名和电话。
- 向患者提供数据保护告知声明，并对需要明确同意的操作取得同意书（使用同意书模板）。

### 诊所与 Klirena 之间的角色

依据数据保护法，诊所是数据控制者，Klirena 是数据处理者。Klirena 仅为提供服务而处理患者数据，不会将其用于广告或其他目的。详情见 klirena.com 上的隐私政策。

### 已删除的记录

被删除的就诊连同其照片、文件和关联的复诊一起从列表中移除，记录保存在归档中。已签署的同意书不能删除。

### 删除账户

请用注册的电子邮件地址，向 support@klirena.com 发送主题为“Account Deletion Request”的邮件。账户和所有诊所数据将被永久删除。在此之前，请从面板下载 ZIP 格式的数据。订阅需要另外在 App Store 或 Google Play 中取消；删除账户不会终止订阅。
